Политика конфиденциальности

приложение «Julia Art Cards»

Редакция от 01.11.2026

1. Общие положения

Настоящая Политика описывает, какие данные обрабатывает мобильное приложение «Julia Art Cards» (далее — Приложение) и в каких целях. Политика подготовлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и требованиями витрины RuStore.

Оператор обработки данных — разработчик Приложения: Дряба Олег Юрьевич. Контакт для вопросов по обработке данных: mr.dryaba@ya.ru.

2. Какие данные обрабатывает Приложение

  • Изображения с камеры. Камера используется исключительно для сканирования физической карты в разделе «Раскрыть карту». Кадры обрабатываются только в памяти устройства: приложение сравнивает изображение с локальными эталонами и не сохраняет, не передаёт и не хранит отснятые кадры после распознавания.
  • Загрузка публичного контента. Приложение обращается к интернету только для загрузки публичных текстов прогнозов (сервер eso3.com). При сетевом запросе серверу технически доступен IP-адрес устройства; эти данные не связываются с пользователем и не накапливаются Приложением.
  • Иные данные. Приложение не собирает персональные данные: не требует регистрации, не использует аналитические и рекламные SDK, не считывает идентификаторы устройства, контакты, геолокацию, файлы и сообщения.

3. Используемые разрешения

  • CAMERA — сканирование физической карты; разрешение запрашивается только при открытии сканера, при отказе остальное Приложение работает без ограничений.
  • INTERNET — загрузка текстов прогнозов.

4. Цели обработки

Обработка изображений с камеры и сетевых запросов выполняется исключительно для предоставления функций Приложения (распознавание карты, показ прогноза). Данные не используются для профилирования, рекламы, рассылок и иных целей.

5. Хранение и удаление данных

Приложение не хранит данные пользователей на серверах: всё, что вводится или снимается, остаётся на устройстве и удаляется операционной системой при удалении Приложения. Персональные данные ни на устройстве, ни вне его не накапливаются, поэтому отдельный порядок их удаления не требуется.

6. Передача третьим лицам

Приложение не передаёт данные пользователей третьим лицам. Внешние ресурсы, доступные из Приложения, на которые действуют их собственные правила:

  • сервис прогнозов eso3.com — только запрос публичной страницы;
  • магазин колоды в VK (m.vk.ru) — переход по инициативе пользователя при нажатии кнопки «Купить колоду».

7. Дети

Приложение не ориентировано на детей младше присвоенного возрастного рейтинга и не собирает данные детей. Приложение не содержит покупок внутри Приложения, рекламы и форумов пользовательского контента.

8. Изменения Политики

Актуальная редакция Политики всегда доступна на этой странице. Существенные изменения публикуются с обновлением даты редакции.
